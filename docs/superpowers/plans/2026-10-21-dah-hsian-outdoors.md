# 達賢戶外獨立區域建置

## 目標與範圍

依本輪已確認範圍，建立能行走的達賢戶外獨立場景：本館、草坡入口、池岸與湖濱悅讀小屋。交通銜接、室內、NPC 與任務留待之後。使用者另要求增加圖片參考、盡量還原，依 docs/reference/dah-hsian/README.md 與 manifest.json 製作，沿用 DESIGN.md 的既有風格。

## 架構與介面

```mermaid
flowchart LR
  A[逐圖參考與 OSM 輪廓] --> B[達賢配置與高度資料]
  B --> C[模型及碰撞]
  C --> D[既有獨立場景機制]
  D --> E[既有角色與操作]
```

- 自己的目錄 src/world/buildings/dah-hsian/；不匯入其他建築。
- layout.js 提供配置、地面高度、區域名稱與水岸限制；model.js 可在 Node 建立幾何，map.js 接入既有材質與碰撞。
- index.js 的戶外 build 留空，只登記獨立場景；沒有通往達賢的校園入口。
- 查詢參數 area=dah-hsian 是本輪預覽入口，只在指定時改開始畫面說明並於開始後進入達賢。一般網址維持原流程。
- 不改 rooms、gameplay、角色、共用碰撞或存檔格式。所有新建內容第一次進入才建立。
- 測試透過 scripts/dah-hsian.test.mjs 加入既有 npm test；既有 smoke 會自動遍歷新場景。另加達賢真實瀏覽器驗收，核對預覽入口、移動、碰撞與懶載入。

## 垂直實作與驗證

### 1. 草坡、池岸與建築間可步行

- Red：一個高度測試驗證入口、草坡及池畔之間有有限且連續的地面。
- Green：只實作對應配置、地面高度；執行 node --test scripts/dah-hsian.test.mjs。
- Refactor：同一高度來源供視覺地形與玩家腳底使用。
- 下一循環才加入水岸及範圍限制測試，先以已知方形校準多邊形判斷，再確認角色不跨入實際池面；最小實作並重測。
- 再下一循環加入建築碰撞與完整戶外路線測試，使用真正的 resolve() 而非假碰撞；最小實作並重測。

### 2. 還原戶外可見內容

- Red：以已知水平面校準 Three.js 射線，再驗證可見地面與高度查詢一致。
- Green：產生貼合地形的地面與石板步道；同一測試檔通過後才做下一項。
- 本館、空橋、小屋、景觀池依參考製作，靜態造型由實際畫面對照驗收，不寫只重述色碼與網格名稱的測試。
- 重複窗格、遮陽板、樹與欄杆共用幾何或 InstancedMesh。沿用既有卡通材質；場景最多天光加主燈，不增加陰影燈。

### 3. 獨立場景預覽

- Red：真實瀏覽器驗證指定 area 後按開始會進入達賢，正常網址不建立達賢模型。
- Green：最小登記與預覽啟動，不新增正式交通入口；同一瀏覽器測試通過。
- 續測：角色前進、建築阻擋、池岸阻擋、重入不重建、退出回原校園；手機觸控可走動，畫面無橫向捲動。
