# 科系探索第二批與介紹美術

## 背景與基準
Wenzel 在一期攤位瀏覽功能之後要求「開始做下一步跟 科系介紹美術可以優化一下」。本批依既定第二批範圍，加入收藏、比較與明示為設計示例的學習情境，不更動已查核的科系與招生研究。

開工核對時間：2026-10-22 07:50（臺灣時間）。一期 PR #78 已合併；本地獨立工作目錄從 main 13c1c8d8ef32368fff167eb0ac99ae8efbccbb25 精確下載建立。此說明記錄核對時間，不宣稱是原始訊息發送時間。

## 互動
- 科系介紹選擇「喜歡課程／喜歡出路／還想了解」即可收藏，再點同一理由取消；全部取消則移除收藏。
- 活動 HUD 的「我的探索清單」可查看完整介紹、定位到活動地圖、加入比較或移除收藏。定位只標記地點，不傳送角色。
- 最多比較 3 系。桌面並排課程、出路與申請準備；手機按比較項切換，逐系卡片不縮成細小橫表。
- 37 系各有一則「你會做什麼」學習情境，明示為作者設計示例，不是官方必修課程或作業。
- 介紹採奶油白、深藍、茶綠海報式主標，學院色識別、課程卡片與較大的手機文字；尊重 reduced motion。

## 資料與生命週期
收藏只以版本、科系 ID 與固定理由代碼存於本瀏覽器 localStorage；不儲存人身資料、不登入、不傳送、不跨裝置同步。比較名單僅本次記憶體。

資料損壞、未知版本、storage 拒絕或容量不足時，保留可用的本次記憶體功能並提示。清空只操作本功能儲存鍵；刪除被拒時不保證舊瀏覽器資料已清除，畫面須說明。

沿用同一資訊卡 modal 的移動鎖、焦點隔離及退出活動收起機制；地圖星號由共用儲存狀態產生，原本實體看板預設不改。測試保留舊資料、NPC、佈景與碰撞回歸。

## 驗收界線
本地 Node / DOM 模型驗證與 build 不等於瀏覽器視覺驗收。已擴充既有 opt-in Playwright 與真遊戲截圖腳本，涵蓋收藏、三系比較、手機比較項與地圖星號。需要在獲授權且可啟動 Chromium 的環境實跑並核對同版截圖後，才可宣告視覺通過。本地完成後，Wenzel 進一步回覆「合併部署」，已授權 PR、驗收通過後合併與部署。所有發布狀態以 GitHub 實際結果與同版截圖為準，不以本文件宣告完成。
