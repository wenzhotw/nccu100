# 室內空間（房間）

遊戲的室內做法跟寶可夢、薩爾達、上古卷軸一樣：**進門就換場景**。

- 每個室內是一個獨立的場景，有自己的碰撞、燈光、背景、地面高度和區域名稱。
- 走到門口按「進入」，畫面淡出，換成房間的場景，主角出現在房間的出生點；出來時反過來。
- 在室內時校園完全不畫，室內再多手機也一樣順。
- 室內可以比外觀大（裡面比外面大），不用跟外觀尺寸對齊。
- 房間第一次走進去才建立，遊戲一開始不用載入所有室內。

程式在 `src/core/rooms.js`（場景、碰撞切換）和 `src/core/gameplay.js`（門、進出）。

## 加一個室內

### 1. 建立檔案

```sh
npm run new-interior -- swimming-hall
```

會在 `src/world/buildings/swimming-hall/` 建立 `interior.js`（地板、四面牆、出口門的空白模板），並印出要貼進 `index.js` 的設定。

### 2. 在建築的 index.js 登記

```js
import { buildInterior } from './interior.js';

export default defineBuilding({
  id: 'swimming-hall',
  name: '游泳館',
  build,
  interior: {
    build: buildInterior,                                    // 建模：照常用 block()、mk()、boxC()
    entrance: { x: -118, z: -118, label: '進入游泳館' },       // 戶外的門（校園座標）
    spawn: { x: 0, z: 18, face: Math.PI },                   // 進門後站的位置（房間座標）
    exit: { x: 0, z: 20, label: '離開游泳館' },               // 房間裡的出口
    returnTo: { x: -118, z: -116, face: 0 },                 // 出來後站的位置（校園座標）
    bounds: { x0: -15, x1: 15, z0: -30, z1: 20 },            // 主角能走的範圍
    camera: { x0: -15, x1: 15, z0: -30, z1: 21, ceil: 9 },   // 鏡頭範圍與天花板高度
  },
});
```

房間的座標從原點開始算就好，跟校園的座標無關（兩邊是不同的場景，不會重疊）。

### 3. 欄位

| 欄位 | 必填 | 說明 |
| --- | --- | --- |
| `build` | ✓ | 建模函式。裡面照常用 `block()`、`mk()`、`plane()`、`boxC()`，系統會把它們搬進房間的場景和碰撞 |
| `entrance` | ✓ | 戶外的門：`{ x, z, r, label }`，`r` 是多近會出現按鈕（預設 2.8） |
| `spawn` | ✓ | 進門後主角的位置：`{ x, z, face, yaw, pitch }`。`face` 是主角面向，`yaw`、`pitch` 是鏡頭角度 |
| `exit` | ✓ | 房間裡的出口：`{ x, z, r, label }` |
| `returnTo` | ✓ | 出來後主角在校園的位置：`{ x, z, face, yaw, pitch }` |
| `bounds` | ✓ | 主角能走的範圍：`{ x0, x1, z0, z1 }` |
| `camera` |  | 鏡頭範圍：`{ x0, x1, z0, z1, ceil, maxDist }`。`ceil` 天花板高度、`maxDist` 鏡頭最遠距離（預設 6.5） |
| `id` |  | 房間代號，預設是建築 id。一棟建築有好幾個房間時要各自取名 |
| `name` |  | 顯示名稱（區域橫幅、小地圖），預設是建築名稱 |
| `heightAt(x, z)` |  | 房間裡可以走上去的高度（舞台、階梯），回傳數字；沒有就是 0 |
| `zone(p)` |  | 房間裡的區域名稱，例如分成「大廳」「更衣室」「泳池」；沒有就用 `name` |
| `clamp(p)` |  | 額外的走動限制（例如舞台兩側的牆） |
| `light(scene)` |  | 自訂燈光，把燈加進 `scene`。沒寫就用預設的天光加一盞主燈 |
| `background` |  | 背景顏色（看出窗外或天花板以上時的顏色） |
| `onEnter()`、`onExit()` |  | 進門後、出門前要做的事（例如播音樂） |

### 4. 一棟建築好幾個房間

`interior` 可以是陣列，每個房間要有自己的 `id`：

```js
interior: [
  { id: 'admin-1f', name: '行政大樓一樓', ... },
  { id: 'admin-3f', name: '行政大樓三樓', ... },
],
```

房間之間的樓梯或電梯，用 `enterRoom('admin-3f')` 切換（從 `core/gameplay.js` 匯入）。

同一個建築裡相連的空間（例如游泳館的大廳、更衣室、泳池）建議放在同一個房間裡用牆和門洞隔開，直接走過去，不用每次都淡出淡入。

## 房間裡的 NPC、校園故事

- NPC（`src/content/npcs.json`）：加 `"room": "房間 id"`，NPC 就會在那個房間裡。舊的 `"indoor": true` 等於四維堂。
- 校園故事（`src/content/stories.json`）：加 `"room": "房間 id"`。舊的 `"inside": true` 等於四維堂。

不在主角所在場景的 NPC 會暫停，不畫也不動，回來時從原本的位置繼續。

## 程式裡要判斷的時候

- `indoor()`：主角在不在室內
- `state.room`：主角所在的房間 id，戶外是 `null`
- 互動點（`spots`）加 `room: '房間 id'` 只在那個房間有效；沒寫的是戶外的互動點，在室內不會出現

## 效能規格（手機也要順）

- 一個房間的燈光最多 3 盞，不要開陰影
- 重複的東西（椅子、置物櫃、窗格）用 `InstancedMesh` 或貼圖
- 房間面積建議 60 × 60 公尺以內

## 室內規劃

| 等級 | 做法 | 例子 |
| --- | --- | --- |
| A 級：主要室內 | 完整內部、有 NPC 和劇情 | 四維堂（已完成）、游泳館、中正圖書館、行政大樓、體育館 |
| B 級：小室內 | 一兩個房間，一個重點 | 集英樓餐廳、書局、郵局、各院館大廳 |
| C 級：不做室內 | 門關著，或按了只出現一句話 | 大部分宿舍、教室大樓 |
