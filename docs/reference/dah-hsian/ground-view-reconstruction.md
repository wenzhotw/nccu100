# 從角色站位重建達賢：取景與缺口

研究日期 2026-10-21，基線 v1.52／51a8cb18。本文件保留當時研究觀察；後續 v1.53 已依照片重建，實作、遊戲對照與驗收結果見 [重建 QA](rebuild-qa.md)。以下「現版／下一輪」均指研究時基線，不能把歷史缺陷當成最終版本狀態。

## 使用者要求與製作方式

要在角色可能站立的位置，以接近站立視線的照片理解四周，並在遊戲同位置、同朝向比較。先確認空間，再製作牆、樑柱、窗框、欄杆、地面與高低差；空拍只輔助判斷配置。各面細節及穿模都在本輪關注範圍。

```mermaid
flowchart LR
  A[實景站位、方向與拍攝時間] --> B[可核對的尺寸與接點]
  B --> C[遊戲可見模型]
  B --> D[地面高度與碰撞]
  C --> E[同站位畫面比較及實際步行]
  D --> E
```

推薦以館方環景核對連續動線，另用較新實拍查現況。備援是攝影者的步行照片序列；它能補環景缺口，但站位、拍攝方向與焦距常需估計，不能把估計值寫成測繪數據。沒有新增付費服務或軟體相依。

- 半圓老樹廣場與階梯近身：ha-06/07、walker-06/07、rtc-11可核對；需再做每段標高／欄杆與現況比對，不能以空拍猜階梯。
- 主樓北側／前側轉角與屋簷底、池對岸一整圈：有散照，但尚未每一段都建立同站位對照；有樹遮擋的地方繼續標缺圖。
- 屋頂：空拍僅核對量體、鋸齒天窗及植栽範圍；非角色地面視角，不能取代上述缺口。

## 已可確認的主要差異

1. **入口空間**：館名牆與入口旁是連續深門廊；玻璃在左，柱／欄杆／長椅在右。不能用一道浮高玻璃與從地面延伸的碰撞箱堵住路。
2. **背側平台**：有寬露台與沿池側玻璃的狹長走道，且與一樓有清楚高低差。現版全場只按z變高的斜坡不足以表達它。
3. **池側立面**：橘褐色直立外框中有橫向百葉，再配混凝土帶與玻璃；不是整面均勻木色細直條。不同側面需分開校正。
4. **小屋接橋端**：混凝土端框、實牆、退縮玻璃與入口不對稱；現版通體規則玻璃盒不足。
5. **空橋**：實景是連續橋面接到兩端平台，欄杆與端牆一起形成空間；模型的接點已有實際缺口，需以共同接點資料重建。
6. **地面**：可見長條石、六角磚、草縫、灰色小方磚等分區，不能用同一排規則石板鋪遍場景。

## 下一輪實作與驗收順序

1. 先把每個照片站位以可見地標對入遊戲；公開經緯度只提供起始近似，視線高度與視野仍需校正。遊戲目前第三人稱鏡頭，不能直接把角色腳底座標當作照片相機座標。
2. 優先重建入口平台、館名牆、門廊與背側露台。一個穿模行為先補一個失敗測試，修到通過，才處理下一項；模型、腳底高度及碰撞共用尺寸。
3. 依次校正各側立面、小屋、空橋接點、老樹廣場及地面分區；有照片依據的外觀直接修，缺圖留記錄。暫不擴入室內／交通。
4. 相機畫面對照檢查比例、遮擋、轉角後出現的內容；再連續步行與轉鏡頭，檢查角色和鏡頭穿模。原本「測試6/6」不足以涵蓋這些新缺陷。
5. 實作後仍需既有TDD、前端兩輪雙尺寸自評、獨立審查、全套檢查與原網址部署後驗收。本文件階段沒有宣稱這些已通過。
