# 達賢戶外驗收紀錄

本輪範圍為獨立戶外場景，非整個專案健檢。Node v24.15.0，Three r149，Chromium 軟體繪圖；真實手機效能未測。程式基底已同步 main 6f0dc8e（含新美術規範），版本 v1.52。

## 圖片與領域核對

36 個不同 SHA256 的研究影像索引含 8 張官方館方圖、3 張建築師刊圖、21 張官方攝影徵件作品、3 張平面圖、1 張有授權標示的空拍。部分為平面及室內採光參考，不宣稱 36 張都是戶外照片。來源、作者與授權見 README.md、manifest.json。依正面、池畔、兩側、屋頂及空拍交叉觀察，不以同角度縮圖充數。

保留本館近方形比例、前草坡、右側入口退縮、斜向混凝土板、玻璃帶、背面褐色細直遮陽、屋頂採光罩、後側景觀池、小屋與空橋的關係。OSM 提供三個外輪廓；官方高度 31.7m 與水平統一乘 0.8。草坡高差、步道與園景細節、外梯及窗格尺寸仍為照片估計。

## QA 角度及實際操作

| 角度與理由 | 操作 | 已觀察的結果 |
| --- | --- | --- |
| 初次探索玩家，確認能到達並行走 | 指定 area，按開始、W 前進、向前牆和池岸移動 | 進達賢，角色可移動，牆與岸線擋人 |
| 手機玩家，確認操作與小畫面 | 375×812、isMobile/hasTouch，操作搖桿 | 角色前進，顯示觸控控制，HUD 與頁面無橫向溢出 |
| 熟悉達賢的校園使用者，辨認地標關係 | 對照官方正面、背面、空拍與小屋平面 | 上述主要建築特徵與相對配置保留；非測繪精度 |
| 場景維護者，確認不影響既有世界 | 普通網址、第一次建立、退出、重新進入 | 普通網址不建立達賢；重入沿用模型；故事與地圖道具狀態不變 |
| 場景與可視性維護者 | 鏡頭進入延後建立的共用樹冠 | 先重現葉片不淡出，修正後真實瀏覽器測試通過 |

這是 AI 多角度與獨立程式審查，沒有真人校方或建築師認證。本輪未改登入、權限、付費、個資或資料輸入介面，未觸發完整攻擊模擬；不宣稱通過全專案資安驗證。

## 已證實缺陷與修正

- 入口館名牆缺碰撞：實際 resolve 原先完全不推離，補相符 box；回歸驗證牆阻擋、旁邊開口可走。
- 小屋露台可穿入：OBB 擴至露台外緣，外梯移到外牆外並補獨立 OBB；回歸驗證外側通路仍可走。
- 375px HUD 溢出：只在達賢作用域壓縮字距、字級與 padding，測試通過。
- 共用樹在 prefab 已合批後延後建立，setFade 為空函式：達賢新樹清除這個空介面，接既有一般網格淡出；瀏覽器先紅後綠。
- 第一輪混凝土偏黃、草地過亮、方形地面邊界與遠丘擋觀景：調整材質／獨立場景光照、延長景觀地面並移遠低丘。
- 原試作 Reflector 缺少浮點色彩能力判斷：曾補檢查與單元測試；同步新美術規範後整個 Reflector 已移除，正式版本使用卡通池面亮紋，不留下已無用途的能力介面與測試。
- 美術硬規則：補主要量體、大構件與石碑的 OUT 描邊，沿用共用樹與字型規範。獨立代理複查碰撞修正通過；後續樹冠問題由真實瀏覽器重現與回歸保護。

## 機械設計檢查與動效範圍

Impeccable 初次回報舊地面預設色與亮紋未登錄。地面改用共用色，亮紋移入 COLORS.waterHighlight 並記錄材料目的。OUT 色加入 DESIGN.md。index.html 僅改版本，獨立 HTML 掃描把未載入 JS 匯入 CSS 的 ● 誤算為黑字；已依 .ico 實際樣式記錄單檔單值例外，已用實際 Chromium computed style 確認為 rgb(255, 250, 239)，與紙色 #fffaef 相同。未停用整條規則或整個檔案。最近 detect 結果為空。

| 動效審查前 | 審查後 | 理由 |
| --- | --- | --- |
| 試作池面即時倒影 | 移除，以靜態卡通波紋表現 | 遵守新美術規範，免額外反射 pass |
| 延後建立的共用樹不淡出 | 使用既有一般網格淡出 | 鏡頭進樹冠仍看得到角色 |

本輪沒有新增 CSS 動畫、UI 過場曲線或 shader 動效。既有 iris 過場未改動，不把局部審查當作既有全部動畫的無障礙保證。Approve：本輪沒有新增無必要／鍵盤觸發的 UI 動效。

## 驗證與限制

- 新增 6 項 Node 行為測試逐項紅綠；全套 npm test：98 通過。
- npm run check、npm run build 通過。build 提示既有 gameplay 同時被靜態／動態匯入，預覽的 import 用來避免初始化循環，沒有宣稱 gameplay 會獨立下載。
- 達賢瀏覽器流程通過；既有全場 npm run smoke 也通過；main 合併後重測及部署後驗收留待收尾流程。
- 幾何統計先用已知 BoxGeometry 校準為 12 三角形，再逐 Mesh 按 index.count/3（或 position.count/3）、InstancedMesh 乘實例數相加。本區靜態模型含描邊為 30,610 三角形，不含共用樹、字樣與石碑，不等於完整一幀或 GPU 記憶體。完整幀另以實際方塊校準：空場景 9 calls／18 triangles，放入單一方塊變為 10／30。相同 1280×800、DPR1、Bloom與後製開啟時，正面全景為 195 calls／39,678 triangles；扣除相同空場景，本區增加 186／39,660。26 個可見模型材質包含借用的共用樹與 OUT，不能直接當作新增材質數。數據與方法見 perf.json，不代表真機 FPS。
- 室內、正式交通入口、NPC 與任務沒有製作。空橋與外梯只有可見外觀，本輪不提供登橋入室流程。微地形與植物不是實地測繪；真機 FPS 未測。

## 美術規範第十三節

1. 已核材質：正式場景由 toon()/basic()/共用 OUT 產生；無寫實材質、外部圖片或 Reflector。Node 的無引擎預設材質僅供幾何測試。
2. 已核顏色：草地沿用 #6fae5c，其餘取相近暖灰、藍灰與褐色，沒有純黑。
3. 已核描邊：主量體、大構件及石碑共用 OUT；細窗框、平貼文字、地面與水面不描邊。
4. 已核造型：正面斜板、玻璃帶、入口懸挑、背面格柵、採光罩與小屋保留。窗格等重複小構件以 InstancedMesh 合批，未逐件建立獨立 draw call；低分段幾何共用。
5. 已核貼圖與文字：僅 canvasTex()，館名用正式建築襯線字，字形不是原書法複製。
6. 已核燈光：另一張戶外地圖依第九節，半球光加單一暖白方向光，不開陰影，沒改原世界天空。
7. 已核尺度：獨立區統一0.8倍，建築內部相對比例與官方高度對齊；所有 position.set 三軸完整。
8. 已核繪製工作量與共用：上述校準及 perf.json；樹沿用 asPrefab 工具，延後建場時依既有機制為一般網格並保留淡出。未測真實手機效能與精確新增材質差值，不宣稱所有建議預算均已證實。
9. 已核最終正面與池畔兩張截圖；「與原校園同框」不適用，使用者明確指定獨立區域，未為截圖自行接地圖。
10. 已核 npm test、check、build 及 smoke；main 與部署驗證按收尾流程另記。
