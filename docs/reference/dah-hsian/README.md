## 已確認的建築錨點

- 正面是兩道大片斜向清水混凝土遮陽板，帶間有水平玻璃窗帶。
- 主樓平面接近方形，不能只依正面照片把它做成薄片；立面下方有退縮與懸挑入口。
- 池畔面呈現木色直條、玻璃與混凝土水平外框，不能套用正面同一個造型。
- 前草坡具長條石板與留草縫步道；側邊有高低差及階梯。
- 小屋為獨棟兩層、扁平屋頂、大面積玻璃、白灰窗框及戶外欄杆，臨池側有支撐。
- 主樓與小屋以空橋及地面步道連接；小屋與池岸並非任意擺放。
- 水池岸線有轉折與石塊、灌木，不是幾何正圓或游泳池。

## 還原層級與未驗證事項

本輪以外輪廓、相對位置、高低差、遮陽系統、主要材質與行走動線為還原重點，沿用既有卡通渲染。不是工程測繪或完整數位孿生。

外牆精確厚度、遮陽板角度、每個窗框間距、池岸每塊石頭及地面精確標高仍由照片估計；不標成現地實測。草坡高差需對照入口及小屋照片再驗收。樹木位置只保留主要視線與綠化分布，不假報逐樹定位。
