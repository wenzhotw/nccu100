# 達賢 v1.53 重建與驗收

來源版本 `51a8cb18e2641ac754cc68c2bcb20ab9f1df4666`，工作分支 `fix/dah-hsian-detail-and-collision`。使用者於2026-10-21核可依角色站位照片重建戶外。相片來源及年代限制見 [地面取景研究](ground-view-reconstruction.md)。

## 能力、資料與取捨

玩家可從草坡進入深門廊、繞二樓露台、經主樓外梯上下樓及走空橋到小屋戶外入口。玻璃門仍阻擋進室內；獨立區域暫不接交通。主樓各側材料不同，小屋有退縮入口及不對稱端框，草坡石板、半圓老樹廣場與平台高差分開呈現。

`layout.js` 保存高度、接點、階梯與欄杆配置，`model.js` 生成可見形狀，`map.js` 接既有卡通材質與文字，`index.js` 透過現有角色高度接線。自然地面與高處支撐分開，角色在橋下不被吸上樓；本區局部反覆解相鄰碰撞，不改全遊戲共用引擎。

推薦保留本區高度與配置。備援是擴充共用多層行走引擎，適用未來多張地圖都有相同需求時，但本輪會擴大回歸範圍，故未採。無新增依賴、付費、服務或存檔格式；第三方照片沒有進遊戲資產。原測試中「短門廊位置／整棟封閉小屋／整場單一坡面」的假設已按照片及新的戶外行走範圍更新，沒有以放寬碰撞斷言掩蓋失敗。

## QA 角度及範圍

AI 分別從首次探索玩家（能否走完戶外）、熟悉達賢的訪客（同站位看到的構件）、場景維護者（模型與腳底／碰撞一致）檢查。不是校方或真人專家認證。本輪沒有登入、權限、付費、個資或外部輸入變更，採局部玩家／領域 QA，不對第三方執行安全模擬。

## 產品理解檢查點（提交前）

- 能力：獨立達賢戶外可探索，外梯／橋能走，室內與交通維持原範圍。
- 體驗：門廊保持平坦，兩層不互相吸附，實體欄杆／柱牆阻擋；近身可看各面材料。
- 結構：layout尺寸、model外觀、map材質、index角色高度接線，各在本區。
- 流程：照片地標→共同配置→可見模型與支撐／碰撞→相機對照及真實操作。
- 理由：共用接點減少看得到卻踩不到；不足身寬的窄縫不擴大可見柱，而選最近完整安全點。
- 備援：全遊戲多層行走引擎適合未來多地圖，本輪不擴大共用回歸範圍。
- 安全與成本：無新增依賴／服務／付費／個資／存檔變更，外部照片不發布。
- 證據：21項新回歸、原6項、全套119、check/build，逐項紅綠與獨立審查；瀏覽器最新流程與發布結果仍按後續關卡記錄。
- 限制：估算站位、老環景、部分北側／植栽現況缺圖、真機效能及嚴格前後render增量未核。
