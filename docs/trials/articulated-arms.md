# Phase B1：四角色真手肘與手部掛點試做

來源：main e98c341fe07165dcd6a7db8c40f9b7652b948ed1，v1.87。候選版本為 v1.88。

本輪只處理 chiang、player、bz26-D12、bz26-D23 的可還原手肘與手部掛點。正式遊戲不自動啟用，未完成膝蓋、完整換裝或全部 105 角色遷移。

## 結構與相容性

建構器保存既有前臂與 NPC 手掌模型的直接引用，再由角色來源紀錄驗證。啟用前先檢查左右手與已知服飾，不靠子節點索引猜哪個是前臂，不修改共用幾何或材質，也不釋放共用資源。

NPC 手肘相對肩膀為 y=-0.10，手部掛點為 y=-0.25。主角分別為 y=-0.09、y=-0.21。這些是配合現有卡通模型選定的樞紐，不宣稱符合人體解剖尺寸。主角沒有分開的手掌球，手部掛點只是前臂末端的配件原點，沒有額外加上一顆手掌。

前臂移到手肘群組，NPC 手球移到手部群組；零角度時保留世界空間位置。D12 的整組金融平板跟隨左手。D23 下袖與袖口跟隨手肘，上臂蓬袖仍在肩膀。所有父節點、子節點順序與局部變換在修改前一次保存，停止或失敗時完整還原。重複啟用不新增節點，但仍驗證來源與目前結構；重複停止安全。

主角普通服與泳裝沿用原有材質切換。變成雄鷹前會先停止人類手肘試做，再套用原本雄鷹外觀；變成雄鷹後拒絕重新啟用人類手肘。整片槳形翅膀不會當作前臂折彎。

## 隔離預覽

執行既有 Vite 開發指令，再開啟 `/dev/arm-trial.html`。預覽使用真正的角色建構器與服裝程式，但不載入正式遊戲主迴圈。可選四角色、六種上半身測試姿勢、連續手肘角度、觀看角度，並反覆啟停比對。`sit` 只是上半身壓力測試，不是完整坐姿動畫。此頁不加入正式打包入口。

## 數值驗收

`npm run test:characters` 包含兩個新增測試檔，也保留原本 112 組靜態／結構與 24 組舊姿勢基準，不更新任何 golden。

新增驗證涵蓋：

- 四個真正建構器、零角度時所有既有 mesh 的世界矩陣誤差小於 1e-10。
- 六種有限值姿勢、手隨真手肘移動、手肘到手的距離固定。
- D12 平板與 D23 袖子／袖口的明確父節點。
- 三次反覆啟停，完整序列化結構與世界空間還原。
- 全部 19 個掛載步驟各別注入失敗，驗證完整還原。
- 重複啟用時若前臂被搬走，必須拒絕。
- 普通服、泳裝、普通服、雄鷹轉換時停止與拒絕重啟。
- 每個試點執行真正的 `animateHero` 或 `npcUpdate` 下一幀，包含已掛上的服裝回呼，確認前臂／道具父節點與手肘到手的距離仍正確。

數值通過不代表目視完全無穿模。仍需查看 D23 手肘接縫、D12 平板與臉的距離，以及連續動作。雨傘目前掛在身體而非手，雨天正式動作整合不在本輪。原腿是一整段膠囊，下一階段須真正切分模型，不能只把鞋子掛在新節點就聲稱有膝蓋。

## GRK020 回歸修正

- Grok 自報 D12 坐姿加 90° 手肘時平板穿過領帶、上緣靠近下巴。未取得其原始圖片；本次使用實際模型重現碰撞數值，不宣稱已親眼驗收圖片。
- 統一 `setBendDegrees(0..90)`，所有預設姿勢、滑桿、連續播放使用同一持物補償。回傳要求角度與左右實際角度，沒有暗中限幅。D12 左手保持低位閱讀，15° 以後左肩外展 0.35 rad、左手腕反向補償；其他角色不變。D12 panic 的右手維持驚慌動作，但持板左手不再高舉。
- 每個姿勢以 1° 步距掃過 0–90°，4–90° 的平板零件與實際領帶 OBB 不相交，平板最高頂點低於頭球最低 y=.718。這只是特定幾何回歸，不代表衣領、手臂、其他全身穿模或視覺美感已通過。
- 0° 中立模型本來存在平板／領帶包圍體交集；為保留原世界矩陣，0–3° 過渡區仍列既有限制，不能聲稱全角度無接觸。獨立同量尺對照確認此區沿用且減少舊中立接觸；10–14° 沒有跳變。正式採用前仍需 Grok 實際前、側、斜視圖覆驗。
- 外部將 trial.hand 或 trial.elbow 重掛至角色或其他容器時，停止會依物件引用清除全部自有暫存節點，不用名稱掃描刪除別人的節點；已測重掛、停止及連續再啟用。
- 目前仍是隔離頁／明確呼叫 API 的姿勢驗證。舊 costume `n.after` 會改肩角，日後整合遊戲迴圈須在舊動畫 callback 後套用閱讀姿勢；本次不宣稱主迴圈已採用或已通過動態防碰撞驗收。
