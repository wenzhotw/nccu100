# 包種茶節常設活動 v2

本分支以 main `380d79e58b2b343165c51089bade5099fc2a75fd` 為基底，只整合活動增量，保留達賢二樓、地形、版本、CI 與既有系統。沒有複製候選 ZIP 的舊版完整 app，也沒有部署。

## 如何參加

這是原校園內可開關的會場，不是另一張地圖，也沒有日期限制。

1. 在校門附近 `(-2, 17)` 找「茶香邀請人」，按 E、F、Enter 或畫面的互動按鈕，選「好，我要參加」。
2. 40 頂帳篷、37 個系攤與功能攤位出現；護照會自動掛上，可用右上按鈕或 P 開啟。
3. 在櫃檯前與系攤 NPC 對話答題集章；不需要進帳篷。集齊一院章可到四維堂挑戰該院關主。
4. 任三枚學院勳章可開茶香大會考，十題答對七題通過。服務台可用三點茶葉點數換提示卡。
5. 服務台或邀請人的「離開會場」會收起場景，但保留進度；大會考通過亦收起。再次接受邀請可重玩，本輪大會考狀態重設，累積章與勳章保留。

成就為「茶香探索者」（大會考）、「政大通」（十一院勳章）、「全系制霸」（三十七系章）。既有瀏覽器存檔系統保存活動旗標。

## 驗證

- `npm ci` 安裝依賴；本機可加 `--cache /tmp/baozhong-npm-cache`。
- `npm run check`：既有結構與內容檢查。
- `npm test`：既有 129 項測試，再執行 `npm run test:baozhong` 的 80 項活動測試。
- 活動測試先重新產生平地落地／保存還原回放，再驗證結果；這不是瀏覽器真存檔測試。
- `npm run build`：最新 main 整合後為 212 個模組。
- `npm run smoke`：既有瀏覽器測試，再執行包種茶節邀請、D26 真問答得章、護照、離場、重入與真 localStorage 重載測試（定位使用 debug teleport，互動走真鍵盤與 DOM）。PR CI 還會執行達賢二樓進出與手機操作回歸；這不等於包種茶節手機驗收。
- `node --test tests/independent-entry-regressions.mjs`：保留的額外診斷，原有 core resolver 在非法重疊 spawn 的案例有已知失敗，該測試沒有呼叫活動 v2 恢復。刻意不列入預設 80 項全過，不能把它描述成全引擎無問題。

先前非作者在 `82f2f36` 以同四個活動 hash 通過 D26 前櫃接近、對話、答題得章、退出與重入；不是本分支最新 main 的完整瀏覽器驗收。本次本機 Chromium 因執行環境 socket 限制未能啟動，瀏覽器回歸交由 PR CI。未提供本次場景截圖。

## 已知限制

- 正式範圍是前櫃互動。飛入帳內可能需要再飛出：關閉對話／護照後按 Space 起飛，飛到帳外落地。D26 沒有全域離場按鈕。
- 恢復只處理本模組實物重疊，在一公尺內找安全外緣；未知障礙或地形不符時保留原位並警告，不任意傳送。
- 尚未驗證包種茶節真手機效能、全場動線／地形、瀏覽器真存檔重載，以及所有系攤／關主逐一端到端。
- 美術規範十項：材質、描邊、造型、文字距離、顏色、尺度與場景同框截圖仍待視覺驗收；未新增戶外燈光（程式已核）；效能未量測手機與 render calls；檢查指令依本 PR 實際紀錄，不將靜態／Node 測試當畫面驗收。
