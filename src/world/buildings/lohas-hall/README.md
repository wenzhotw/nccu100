# 樂活館

狀態：依四張外觀照片製作的明亮卡通外觀模型，整合至校園場景。沒有製作室內。

## 造型與參考

- 白色長棟、三排紅／藍綠／米色凸框，以及退縮的地面層窗帶。
- 西端稍高且錯位的四排窗量體，底部玻璃入口及小雨棚。
- 正門端深綠玻璃低翼、粗黑轉角窗盒、開放柱廊、四級階梯及中空愛心。
- 直排「樂活館」與彩色英文館名。
- 沿用既有大仁樓、游泳館的純色低模風格，不製作污漬、密集磁磚或小告示。

參考使用者於 2026-10-12 提供的 `IMG_8754.jpeg`、`IMG_8757.jpeg`、`IMG_8760.jpeg`、`IMG_8761.jpeg`。背面、屋頂配置、實際進深與尺寸沒有足夠照片依據，採簡化推估，並非實測復原。

## 方位與整合

主體沿用預定地中心 `(38, 3)`、寬 26、深 10。長彩窗立面朝 `-Z` 的八德道，較高西端位於 `+X`。較低玻璃翼位於 `-X` 的正門端，最東側落在世界 `x = 17.19`，壓縮相片比例以保留既有門房、樓梯、樹木與圍籬。英文館名移到相鄰白色轉角牆，避免壓縮後被低翼遮住。

柱廊及階梯共用 `layout.js` 的尺寸。階梯前緣世界 `z = -3.4`，開放柱廊可進入，門後室內不開放。柱、門牆和愛心均有碰撞；主牆及樓板保留一般 Mesh，供既有鏡頭避牆使用。重複窗框依顏色合批，館名字型支援字型就緒後重畫。

新增本資料夾，並移除 `src/world/lots.js` 的樂活館預定地一行，不改正門或其他建築。另於 `environment/grass.js` 讀取建築透過 registry 登記的選用 `excludeGrassAt(x, z)` 函式；只有樂活館登記，防止草穿過主體、柱廊與階梯。除草邊界使用本館共用尺寸並留 0.3 公尺草葉風擺餘量，其他建築與地形的取樣規則不變。

## 驗證與預覽

```sh
npm run check
npm run build
node src/world/buildings/lohas-hall/check-model.mjs
```

`__game.teleport(20.8, -5)` 可到柱廊階梯前，`__game.teleport(45, -6)` 可看長立面。

預覽由實際 Three.js 模型幾何與貼圖離線卡通渲染，不是遊戲截圖。雲端瀏覽器 WebGL 停用，尚未完成遊戲內人工走動驗收。

目前已通過結構檢查、Vite 建置、16,728 個行走表面高度取樣、四級階梯及柱廊通行、固定障礙物、十組鏡頭射線、字型重畫與正門周邊間距測試。模型共 29 個可繪物件、3,922 個三角形，重複細節依材質合批。

獨立審查另以既有樹冠的三角形與描邊檢查所有旋轉角度；低翼樓板及柱向內縮 0.3 公尺，最小間距約 0.19 公尺。既有樹木維持原位。
