## 位置

2025 年啟用的新院館，蓋在憩賢樓原址（校區地圖 D3）。在四維道南側、環山一道東側，跟中正圖書館隔著環山一道。西端窄面正對環山一道和四維道的路口。

## 外觀重點

| 部位 | 做法 |
| --- | --- |
| 量體 | 8 層樓長條板樓，東西長 54、南北寬 16、主體高約 27（遊戲比例） |
| 西端窄面 | 深灰牆，北半部白色大框，框內兩個橘色凸盒，框頂立「College of LAW」字牌 |
| 長邊立面 | 一樓深色退縮加白柱；二三樓玻璃帷幕；白色挑出厚板；上面五層白色橫線板加橘色直格柵；靠西端 12 公尺是素面灰牆 |
| 屋頂 | 白色挑出平板，屋頂上兩個深灰色機房 |
| 入口 | 北面，白色門框加「College of Law」字，前面三階台階，旁邊清水混凝土「法學院」石碑 |
