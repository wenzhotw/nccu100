# 電算中心與資訊大樓

- 負責人：@wenzhotw
- 狀態：第一版完成（塔樓、連接翼、資訊大樓、台階、石牌、碰撞、區域名稱、地圖圖示）
- 參考照片：`photos/`

## 位置

校區地圖 A14（電子計算機中心）與 B14（資訊大樓）。兩棟實際上連在一起，所以做成同一個建築資料夾。在正門進來右手邊、果夫樓西側，四維道和八德道之間。

## 外觀重點

| 部位 | 做法 |
| --- | --- |
| 電算中心塔樓 | 約 8 層，正面朝南。一樓退縮有柱子和玻璃門、前有三階台階；二樓帶狀窗；中段白色磁磚實牆，中間灰色石框、四扇窗、兩個菱形；頂部兩層退縮格柵；最上方中央凸起帽頂與通風格柵 |
| 東南角圓柱 | 整棟高，頂端扇形窗，下面一個圓形裝飾 |
| 西側量體 | 較低的階梯狀量體 |
| 連接翼 | 四層，正面是開放走廊，藍色欄杆 |
| 資訊大樓 | 頂上實牆寫「資訊大樓」，屋頂圓形水塔 |

遊戲裡的區域名稱分成「電算中心」和「資訊大樓」兩塊。
