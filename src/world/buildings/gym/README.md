## 室內（interior.js）

門口在內凹門廊裡，按「進入體育館」換場景。房間座標：出口在 +z，越往 -z 越裡面，球場長邊沿 x。

- 一樓大廳：木紋條紋地板、兩座往 2F 看台的樓梯（踏階貼「NCCU GRIFFINS」「雄起來打」，目前不能走上去）、電子看板、兩側獎盃櫃、身高牆、證件查驗桌。大廳天花板是南側看台的底面
- 左右兩個柵欄門通往一樓球場：FIBA 尺寸 28 × 15 公尺的楓木地板，畫了籃球、羽球、排球的線
- 深藍色場邊防撞軟墊，上面是看台：東西兩側各十排、北側五排、南側十排蓋在大廳上面，椅子橘、灰、白混排（`InstancedMesh`）
- 天花板一片片錯落的木質吸音板（`InstancedMesh`）、藍色桁架籃架、北面木牆的布條與錦旗、計分板

照片裡北面布條有一面是運動品牌標誌，遊戲裡改成「雄起來打」。
