## 一、這張地圖是什麼

山上校區是**另一張獨立地圖**，用校園公車和山下校園連接：

| 位置 | 互動 | 結果 |
| --- | --- | --- |
| 山下：行政大樓左側騎樓的乘車處（候車長椅、時刻表旁） | 「搭公車上山」 | 播公車轉場，出現在山上公車站北側 |
| 山上：南邊的山上公車站站牌旁 | 「搭公車下山」 | 播公車轉場，回到行政大樓乘車處 |

技術上它跟室內一樣是**換場景**（`src/core/rooms.js`）：

- 山上和山下不會同時運算，所以山上可以放心加內容，不會拖慢山下。
- 山上的東西**第一次搭公車上山才會建立**，遊戲一開始不會載入。
- 在山上時 `state.room === 'uphill-campus'`，`indoor()` 會回傳 `true`（系統把它當成一個「房間」）。所以下雨、自動存檔、警車、傳教士這些山下的系統在山上不會運作，這是預期中的行為。

## 三、絕對不能做的事（避免衝突）

1. **不要 import 其他建築資料夾**（`../library/` 之類）。`npm run check` 會擋下來。需要共用的工具，請開 Issue 討論是否放進 `src/world/building-kit.js`。
2. **不要改共用檔案**：`src/core/`、`src/render/`、`src/world/registry.js`、`src/systems/`、`src/ui/`、`index.html`、別人的建築資料夾。這些由專案主負責人（@wenzhotw）維護。真的需要時，先開 Issue 說明要改什麼、為什麼。
3. **不要移動山上公車站 `STOP`**，也不要改 `index.js` 裡的 `entrance`、`returnTo`。山下的乘車處座標屬於行政大樓，搬動會讓公車接不起來。（2026-10-19 例外：經 Issue #55 同意，站牌移到山居學習中心南側路邊；`entrance`、`returnTo` 沒有改。）
4. **不要改 `id: 'uphill-campus'`** 和資料夾名稱。NPC、故事、存檔、測試都用這個 id。
5. **不要直接推到 `main`**。一律開分支、送 PR。
6. **不要把山上的東西加到山下**（例如在 `build()` 裡蓋東西）。`index.js` 的 `build()` 刻意留空。

## 四、協作流程

1. 開工前到 GitHub 開一個 Issue（或在既有 Issue 留言），寫「我要做山上校區的 ○○」，避免兩人做同一件事。
2. 從最新的 `main` 開分支，名稱用 `uphill/做的事`，例如 `uphill/dorms`、`uphill/trail`、`uphill/npc-guard`。
3. **一個 PR 只做一件事**（例如「蓋莊敬宿舍」），改動小、好審、好合併。
4. 送 PR 前在本機跑：
   ```bash
   npm run check
   npm test
   npm run build
   ```
   CI 還會跑 `npm run smoke`，會自動搭公車上山檢查一次。
5. PR 說明照模板寫，**附一張山上校區的截圖**，並勾選「只改了自己負責的資料夾」。
6. 合併前如果 `main` 有更新，先把 `main` 合進你的分支（或 rebase），解決衝突後再合併。

### 版本號（最常見的衝突來源）

專案規定每個合併的 PR 版本號加 0.01，要改三個地方：`index.html` 的 `.ver`、`package.json`、`package-lock.json`（兩處 `version`）。多人同時開 PR 時這裡一定會衝突。規則：

- **版本號在最後合併前才改**，改成「目前 `main` 的版本 + 0.01」。
- 衝突時以 `main` 為準再加 0.01，不要兩邊都保留。
- `npm test` 會檢查三個地方是否一致。

### 台詞、NPC、校園故事

放在 `src/content/*.json`（共用檔案，但允許新增）：

- **只在陣列最後面新增**自己的項目，不要改動、重排別人的項目，衝突會少很多。
- 要放在山上的 NPC 或故事，加 `"room": "uphill-campus"`。座標用山上校區的座標。
- id 開頭加 `uphill-`，例如 `"id": "uphill-guard"`，避免撞名。
- 格式說明見 `docs/content.md`。

## 五、座標與地形

- 單位公尺，座標**從原點開始算**，跟山下校園無關。
- **公車站在南邊**：z 越大越南、越小越北；x 越大越東（右）。原點是原本的山居下車點；站牌 `STOP` 現在在山居學習中心南側路邊，玩家下車後面向東北，看得到山居、九舍和往安九的路。
- 地圖範圍 x −120 到 120、z −95 到 100（`R`）。水平約實際 × 0.6，高度約實際 × 0.75。
- 在遊戲裡查座標：`npm run dev` 後，瀏覽器主控台輸入 `__game.pos`。
- **三層地形**：第一層 0 公尺（環山一道、蔣公銅像、好漢坡站）、第二層 12 公尺（五六七八舍、山居）、第三層 15 公尺（九舍、十舍）。分區寫在 `REGIONS`，空隙由 `FILL_REGIONS` 補滿；高度一律用 `terrain.js` 的 `heightAt` 查。
- **連接方式**：第一、二層之間走好漢坡階梯（每階高 0.3、深 0.8，每 12 階一個平台）；第二、三層之間走外部斜坡（從五六舍道路的 T 字路口開始，平滑爬升）。好漢坡東支線接在斜坡中段。
- 層與層交界的非通路處會自動長出擋土牆並加上碰撞，不會掉下去。
- 五舍和六舍之間的連通段是高架（`BRIDGES`），下方的柏油路可以通過。
- 舊的 `PLATFORMS` 保留給簡單的方塊平台，目前沒有使用。

## 六、建築風格

整個遊戲的目標是**任天堂／原神式的明亮卡通風**，同時**依照片手工建模**：比例和距離可以示意，但外觀特徵要讓政大人一眼認得。

### 造型

- 用簡單幾何（方塊、圓柱、球）拼出建築，**抓特徵不抓細節**：外牆顏色與材質、窗戶排列、屋頂形狀、入口位置、招牌文字。
- 每棟建築先找 2 到 5 張實景照片放進 `photos/`，在檔案開頭註解寫「依哪幾張照片」。
- 窗戶、磚牆、招牌用 `canvasTex()` 畫成貼圖，不要用大量小方塊堆。
- 參考寫得好的例子：`../admin-building/index.js`（花崗石貼圖、坡道、站牌）、`../swimming-hall/`（模型、配置、室內分檔）。只能看，不能 import。

### 顏色

- 明亮、飽和度適中的色票，例如草地 `#8fca6c`、木頭 `#a57a4f`、政大綠站牌 `#2f6f4f`、警示橘 `#e8a33d`。
- 避免純黑 `#000` 和純白 `#fff` 大面積使用；陰影色用帶藍或帶紫的深色。

### 工具（`src/render/kit.js`）

| 用途 | 函式 |
| --- | --- |
| 卡通材質 | `toon('#顏色')`（會自動共用）；有貼圖用 `toon('#ffffff', { map })` |
| 不受光的材質（招牌文字、發光） | `basic({ map })` |
| 方塊 | `block(x, y, z, 寬, 高, 深, 顏色, 黑邊粗細)`；`y` 是中心高度 |
| 任意形狀 | `mk(geometry, 材質, x, y, z, { out: 黑邊粗細 })` |
| 地面貼片 | `flat(寬, 深, 顏色, x, y, z)` |
| 立面貼片 | `plane(寬, 高, 材質, x, y, z, 繞x, 繞y)` |
| 畫貼圖 | `canvasTex(寬px, 高px, (g, w, h) => { ... }, [重複x, 重複y])` |
| 碰撞 | `boxC(x0, x1, z0, z1)`、`circC(x, z, r)`（`src/core/collision.js`） |

- **黑邊**：主要量體加 `0.03` 到 `0.07` 的黑邊（`block` 第 8 個參數或 `{ out }`），小東西不加。這是卡通風的關鍵。
- **文字**：中文用 `"Noto Sans TC"`，標題可用 `"Noto Serif TC"`。

## 七、效能規格（手機也要順）

- 燈光：已經有天光加一盞主燈（`map.js` 的 `mapLight`），**不要再加燈**，最多 3 盞，**不開陰影**。
- 重複的東西（樹、路燈、椅子、窗格、圍籬樁）用 `InstancedMesh`，參考 `map.js` 的 `fence()`。
- 形狀（`new THREE.XxxGeometry`）放在函式外面共用，不要在迴圈裡 new。
- 貼圖用小尺寸 canvas（512 × 512 以內），重複用 `[重複x, 重複y]`。
- 建築數量多了以後，用 `npm run dev` 加網址 `?perf` 看效能面板，手機實測一次。

## 八、測試

- 直接上山：`npm run dev`，開始遊戲後在主控台輸入 `__game.enterRoom('uphill-campus')`；下山輸入 `__game.exitRoom()`。
- 走公車流程：主控台輸入 `__game.teleport(32.2, -88.5)` 走到行政大樓乘車處，按 E 搭公車上山。
- 在山上瞬間移動：`__game.teleport(x, z)`（山上座標）。
- 每個 PR 都要確認：上山、下山都能切換，背包和故事數沒有消失，主控台沒有紅字錯誤。
