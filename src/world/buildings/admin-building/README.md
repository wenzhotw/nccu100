## 筆記

四維堂右側，旁邊有車可以走的道路。

- 外牆是灰色花崗石（帶黑白小斑點），方形深窗。
- 門前有一條紅磚坡道沿著立面，從左邊車道那一側往右上升到入口平台的高度（1.2 公尺），右端三階下到地面；外側是擋土牆和不鏽鋼扶手。高度由 `walkH()` 計算。
- 入口平台前是三階大階梯接到門前廣場。
- 面對大樓的左邊（靠車道）一樓是騎樓，可以走進去：靠玻璃牆有外梯上二樓、候車長椅和校園公車時刻表；車道上畫了公車停靠區，路邊有「乘車處」站牌。
