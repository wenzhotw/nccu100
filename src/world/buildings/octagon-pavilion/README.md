# 八角亭

- 負責人：@Frankfangcode
- 狀態：第二版（2026-10-22），依實景照片重做
- 位置：沿用遊戲原本預定地 (44, -150)，中心往西挪 2.5 公尺到 (41.5, -149.5)，避開田徑場的「運動場使用須知」看板
- 參考照片：`photos/`（只給人看，不進遊戲畫面）

## 外觀重點

名字叫八角亭，實際上是方形的現代風涼亭：

| 部位 | 做法 |
| --- | --- |
| 屋頂 | 白色方形平頂薄板（7.8 × 7.8），底面是倒過來的四角錐台，從柱子往四邊斜上去，邊緣很薄 |
| 柱子 | 四根白色圓柱 |
| 地坪 | 抬高 0.4 公尺的深灰色地坪，入口（+z）兩階；三面深色低矮牆 |
| 周圍 | 一圈黃綠色矮樹籬，入口留開口；入口旁「B.C類停車場」牌子 |
