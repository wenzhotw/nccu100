# 大仁樓

狀態：遊戲風格第二版。依使用者回饋改為現有校舍使用的純色低模風格，尚未實地量測，未建室內。

## 造型方向

- 中灰色大牆面、奶白色粗收邊、淡藍色平面窗紋。
- 保留四排窗、簡化白色直柱、中央三道遮陽百葉。
- 深灰色大雨棚、凹入入口、抬高平台、九級紅邊大階梯。
- 保留舊式右讀屋簷題字「大仁樓」。
- 刪除洗石子顆粒、窗框微幾何、梯狀小肋、密集磁磚與細扶手。
- 約 842 三角形、76 個幾何實例、23 個可繪物件。主量體保留一般 Mesh 供鏡頭防穿模使用，其餘重複色塊按材質合批。

這一版以使用者提供的法學院遊戲畫面，以及現有 `law-school` 的色彩與窗紋密度為風格基準。
不以寫實建築攝影為目標；建築之間仍保持獨立模組，不互相 import。

## 遊戲整合

沿用原預定地中心 `(150, -13)`，主體寬 26、深 7 公尺。
入口可走上平台；已定義碰撞、地圖圖示、區域名稱。
共用檔案僅在 `src/world/lots.js` 移除大仁樓預定地那一行。

## 檔案及驗證

- `model.js`：獨立 Three.js 模型工廠。
- `layout.js`：共用尺寸與階梯高度。
- `index.js`：既有 `defineBuilding()` 自動載入規格。

```sh
npm run check
npm run build
npm run smoke
```

冒煙測試需要先安裝 Chromium：`npx playwright install chromium`。
開發模式可用 `__game.teleport(150, -2)` 到階梯前。
