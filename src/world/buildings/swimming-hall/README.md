# 游泳館

狀態：照片參考的明亮卡通模型，使用者已於 2026-10-12 確認部署。未建室內、未經實地測量。

## 造型

- 奶油色及淺米色的低矮長立面，後方灰色高館體。
- 深灰粗框長窗帶、淡藍玻璃、側面大方柱與大片窗。
- 藍色直排「游泳」、橘色轉角「館／Swimming Hall」招牌。
- 正面左偏入口、小雨棚、四級階梯與側向坡道。
- 沿用既有校舍純色低模風格，捨去磁磚格紋、金屬細肋及零碎設備。

## 方位與整合

沿用預定地中心 `(-118, -126)`，主體寬 26、深 14。
正面朝 `+Z`，法學院中心位於 `(-118.5, -100)`，因此入口面向法學院。
入口位於局部 `x = -7.4` 的正面左側。階梯最前端世界 `z = -114.85`，距法學院南側碰撞邊界 `z = -108.5` 約 6.35 公尺。

一棟建築一個資料夾，自動載入。共用檔案只移除 `src/world/lots.js` 的游泳館預定地一行。
高度、坡道與碰撞尺寸集中在 `layout.js`；柱子也有碰撞，門前凹入區可走，室內未開放。
主牆和屋頂保留一般 Mesh 供鏡頭射線避牆，重複色塊依材質合批。

## 參考與推估

## 驗證

```sh
npm run check
npm run build
node src/world/buildings/swimming-hall/check-model.mjs
npm run smoke
```

`__game.teleport(-125.4, -113.5)` 可移到階梯前。

本版已通過結構檢查、完整 Vite 建置、9,343 個表面高度取樣、階梯與坡道行走碰撞、鏡頭牆面及低屋簷射線、方位與字型重畫測試。
預覽圖由原始 Three.js 幾何與貼圖離線卡通渲染，並非遊戲截圖。此環境尚未完成 WebGL 遊戲內走動及 Chromium smoke 驗收。
模型約 588 三角形、33 個可繪物件，適合既有低模場景。
