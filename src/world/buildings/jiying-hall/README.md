## 位置

地圖 D17（福利社、書城、餐廳）。在電算中心後面那條校內道路北段的西側，正面朝北，對著往西彎進來的路口。道路本身在 `src/world/terrain/back-road.js`。

## 外觀重點

| 部位 | 做法 |
| --- | --- |
| 東半部 | 高的素面白牆量體，牆上直排「集英樓」；一樓是校園書局，綠色招牌，前面有鋼構棚架 |
| 西半部 | 二、三樓往外挑出，褐色水平帶加整排窗戶；一樓退縮成騎樓，掛深藍色「集英樓餐廳」招牌 |
| 一樓前面 | 黃色矮牆和矮灌木 |
| 四樓 | 往後退的白色量體 |
