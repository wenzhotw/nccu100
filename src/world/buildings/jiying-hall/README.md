# 集英樓

- 負責人：@wenzhotw
- 狀態：第二版（2026-10-22）：位置、方向、量體改照 OpenNCCU 3D 模型，外觀沿用第一版照片特徵
- 參考照片：`photos/`

## 位置

地圖 D17（福利社、書城、餐廳）。在電算中心後面那條校內道路東側、往側門那條路的北邊。
依 OpenNCCU 3D 模型整棟斜放（rotation.y 約 0.436，順時針約 25 度），中心 (117.5, -20)，量體 26 × 16 公尺，正面朝東南邊的路口。
原本的新聞館預定地在集英樓這個範圍裡，新聞館移到四維道步道北側（見 `journalism-hall`）。道路本身在 `src/world/terrain/back-road.js`。

## 外觀重點

| 部位 | 做法 |
| --- | --- |
| 左半部（從正面看） | 高的素面白牆量體，牆上直排「集英樓」；一樓是校園書局，綠色招牌，前面有鋼構棚架 |
| 右半部 | 二、三樓往外挑出，褐色水平帶加整排窗戶；一樓退縮成騎樓，掛深藍色「集英樓餐廳」招牌 |
| 一樓前面 | 黃色矮牆和矮灌木；書局上方一道深色鋼構雨遮（模型上的深色長條） |
| 屋頂 | 模型上的藍灰色；右半部頂上往後退的白色量體 |

碰撞用旋轉方塊（`obbC`），小地圖用自訂 `draw` 畫斜的外框。
