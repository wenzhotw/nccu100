## 一樓內部（interior.js）

- 配置照 `photos/floor-plan-1f.png`（依現場「一樓平面配置暨緊急疏散方向圖」`photos/evacuation-sign.jpg` 重繪）。第一版用的平面圖是錯的，已經換掉。
- 動線：主要入口 → 大廳（東半邊挑高）→ 電梯廳（4 部電梯、對面兩間教室）→ 廁所前走道 → 交誼廳（桌椅座位區、販賣部、教師休息室）→ 北側走廊（兩間教室、樓梯電梯、側入口）。
- 大廳北邊是中庭側（前面放鋼琴）、坐的台階、往二樓的白色樓梯，東邊是玉山國際廳的牆和門，西邊是監控室。
- 程式裡的座標直接寫平面圖上的像素（px, py），用 `X()`、`Z()` 換成公尺，對照平面圖改位置最方便。平面圖不是實測比例，尺寸是估的。
- 便利商店只做店面，招牌用一般的「便利商店」字樣，不畫品牌標誌。
- 坐的台階可以走上去，高度在 `interiorHeight()`；樓梯、玉山國際廳、教室目前只做外觀，進不去。
