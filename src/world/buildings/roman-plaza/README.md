## 筆記

面對行政大樓的右邊，夾在行政大樓和田徑場之間。

- 格局：半圓形（扇形）的開放式迴廊，圍著中間一片草坪。扇形開口朝校外（校門方向，+z），弧形背面朝田徑場。圓心 `C`、內外半徑 `RI`、`RO` 寫在 `index.js` 開頭。
- 外牆：清水混凝土厚柱，柱間是開大圓洞的牆板；每三間留一間通透，從廣場看得到後面的田徑場。頂上一圈混凝土環梁。
- 內側：深色鋼柱與鋼樑，上面是鐵網花架，爬滿藤蔓。
- 迴廊地面鋪灰色卵石，地台高 0.4 公尺（`heightAt`），靠外牆有木條長椅。
- 兩端各有一座爬滿藤蔓的高牆墩。
- 開口前是淺灰白方磚廣場；西側有一條南北向步道接行政大樓旁，一排樹和木椅。
- 照片上的施工圍籬（羅馬廣場地景藝術工程）是暫時的，沒有做。
