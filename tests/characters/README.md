# 角色固定姿勢測試

執行 `npm run test:characters`。此命令包含既有靜態快照、姿勢工具單元測試與 24 組真實模型姿勢快照，亦由 `npm test` 執行。不需修改 CI。

## 基準與範圍

首次姿勢基準來自 main `a40a04e03e618be0515e98fa51bbd41df9bd0784`（v1.84），沿用 `build.mjs` 的 `worldList(root)` 與 FORMAT=3。`snapshots/poses/index.json` 記錄來源與清單，JSONL 保存完整零件清單，而非只有雜湊。

角色為 chiang、一般服裝 player、穿活動服裝的 bz26-D12、bz26-D23。每個角色包含 walk-a、walk-b、raise-hand、wave、sit、panic 六個固定姿勢。這些是關節壓力測試，不代表完整遊戲動畫或視覺截圖。

`build.add` 在序列化原始角色後，直接使用活的 NPC P 或 player H 關節擷取姿勢。player 必須在泳裝與不可逆的雄鷹轉換前擷取。每次擷取只改五個關節的 Euler 旋轉，最後復原數值、順序與矩陣，並驗證原始結構和世界空間不變。既有 CHARACTERS 與既有快照的格式、內容皆不變。

坐姿不含健身房的 rig 降低；步行不含上下起伏和身體傾斜；恐慌是固定關節姿勢，不觸發遊戲恐慌狀態。擷取不執行 npcUpdate、animateHero 或服裝回呼，也不改臉部表情、衣服可見性、材質或幾何。

## 防止基準掩蓋退化

新姿勢測試只讀取基準，刻意不提供自動更新模式。`UPDATE_SNAPSHOTS=1` 或 `structure` 不會更新姿勢快照；既有靜態快照的更新行為保持原狀。未來若真要變更姿勢或外觀，應獨立說明、審查對應 JSONL 差異，不可用重建基準讓回歸測試通過。

工具單元測試另驗證固定值、不可變輸出、無效關節、序列化失敗與復原；真實模型測試驗證 24 組完整清單、各姿勢差異、材質／幾何清單不變，以及重複擷取和失敗後復原。
